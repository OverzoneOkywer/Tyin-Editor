# Tyin-Editor v0.1.4

Rilis ini memperbarui antarmuka editor dengan tampilan monokrom yang lebih
konsisten serta memperbaiki alur pencarian dan peninjauan perubahan Git.

## Antarmuka editor

- Shell aplikasi, dock navigasi, panel workspace, dan tema terang/gelap diperbarui.
- Explorer menampilkan file terbuka, filter berkas, dan status Git workspace.
- Pencarian workspace berjalan di latar belakang, mendukung pencocokan huruf besar/
  kecil, dan dapat membuka file langsung dari hasil.
- Command palette dapat difilter dan ditutup dengan klik di luar.
- Source Control memisahkan file staged dan unstaged, mendukung Stage all dan
  Unstage all, dan menonaktifkan commit jika pesan atau perubahan staged belum ada.
- Tampilan diff memakai warna tambahan/penghapusan yang lembut.

## Batasan

Room, assistant, dan katalog extension masih berupa preview lokal. Push/pull
remote, instalasi extension, AI, dan kolaborasi tersinkron belum tersedia karena
backend pendukungnya belum ada.
