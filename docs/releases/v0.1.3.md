# Tyin-Editor v0.1.3

Rilis ini menambahkan pemeriksaan dan pemasangan pembaruan dari dalam aplikasi
untuk instalasi resmi Windows dan Debian.

## Pembaruan dalam aplikasi

- Tombol **Check for updates** memeriksa GitHub Releases secara manual.
- Aplikasi menampilkan catatan rilis sebelum mengunduh installer.
- Installer dibatasi ukurannya dan diverifikasi terhadap ukuran serta SHA-256
  yang dipublikasikan GitHub.
- Sebelum aplikasi dimulai ulang, perubahan yang belum disimpan dapat disimpan
  atau dibuang.
- Windows memasang pembaruan secara senyap untuk akun pengguna saat ini.
- Debian memakai `pkexec` untuk meminta otorisasi pemasangan paket.

Pembaruan otomatis hanya tersedia untuk instalasi resmi di lokasi default.
Build development atau instalasi khusus tetap dapat diperbarui dengan mengunduh
installer dari GitHub Releases. Versi sebelumnya perlu diperbarui secara manual
ke v0.1.3 sekali untuk mendapatkan fitur ini.
